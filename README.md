# clip-js

A lightweight, reusable JavaScript/TypeScript AI assistant widget for websites and web apps.

`clip-js` renders a floating assistant launcher and conversational panel — complete with suggested questions, light/dark theming, responsive/mobile layout, accessibility, and the original **Clip** mascot — while staying completely decoupled from any specific AI provider or backend. You bring your own endpoint (or a custom transport); `clip-js` only handles the UI and interaction layer.

> **Status:** Early development.

More documentation, usage examples, and API details will be added as the project develops.
